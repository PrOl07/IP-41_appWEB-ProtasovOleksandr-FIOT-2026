Головна Предметна область

Опис предметного середовища

D&D Master's Screen — це вебзастосунок, призначений для допомоги Dungeon Master під час проведення настільних рольових ігор Dungeons & Dragons.

Система об'єднує основні інструменти, необхідні для підготовки та проведення ігрових сесій.

Функціонал

  • перегляд ігрових підказок;
  • робота з листами персонажів;
  • перегляд бестіарію;
  • відстеження бойових сцен;
  • робота з гральними кубиками.

Бізнес-логіка

  1. Користувач відкриває головну сторінку.
  2. Переглядає необхідні ігрові підказки.
  3. За необхідності переходить до відповідного модуля.
  4. Під час бою використовує Battle Tracker.
  5. Для випадкових значень використовує Dice Calculator.

Функціональні вимоги

  • Відображення ігрових підказок.
  • Перегляд листів персонажів.
  • Перегляд інформації про монстрів.
  • Ведення бойового трекера.
  • Виконання кидків кубиків.

Нефункціональні вимоги

  • Робота у сучасному веббраузері.
  • Зрозумілий користувацький інтерфейс.
  • Адаптивність.
  • Логічна структура HTML-коду.
  • Доступність через GitHub Pages.
