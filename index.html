Quick Reference

Основні підказки та правила для швидкої роботи Dungeon Master під час ігрової сесії.

Ability Modifiers

Модифікатор характеристики використовується під час перевірок характеристик, атак та інших ігрових розрахунків.

Combat Order

На початку бою визначається Initiative, після чого учасники виконують ходи відповідно до встановленого порядку.

Armor Class

Armor Class (AC) визначає складність влучання по персонажу або монстру. Результат атаки має дорівнювати AC або перевищувати його.

Основні можливості

  • Character Sheets — збереження персонажів у браузері.
  • Bestiary — пошук і перегляд прикладів монстрів.
  • Battle Tracker — ініціатива, HP та порядок ходів.
  • Dice Calculator — кидки кубиків із різною кількістю граней.
  • Game Tips — швидкі підказки для майстра.

Порядок дій під час бою

  1. Визначити Initiative для учасників.
  2. Встановити порядок ходів за результатами ініціативи.
  3. Виконати ходи учасників.
  4. Оновити HP та інші характеристики.
  5. Перейти до наступного раунду.
